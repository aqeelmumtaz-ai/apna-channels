Privacy policy

Last updated: 24 November 2026

Apna Channels Uploader ("the app") is a private tool used only by the owner of the YouTube channels Apna Sports Updates and Apna LifeStyle Updates.

What the app accesses

With the owner's permission through Google sign-in, the app uses the YouTube Data API to read the name and ID of the signed-in channel, upload videos, add captions and set thumbnails on the owner's own channels.

How data is used and stored

The sign-in token is stored only on the owner's own computer and is used only to upload the owner's videos. The app does not collect, sell, share or transfer any personal data or YouTube data to anyone, and does not use it for advertising.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the Google Privacy Policy.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
