Privacy policy

Last updated: 25 November 2026

Apna Channels Uploader ("the app") is a private tool used only by the owner of the YouTube channels Apna Sports Updates and Apna LifeStyle Updates.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Information handled through YouTube API Services is also subject to the Google Privacy Policy.

What the app accesses

With the owner's permission through Google sign-in (OAuth 2.0), the app uses the YouTube Data API to read the name and ID of the signed-in channel (to confirm it is the right channel), upload videos as private drafts, add caption tracks and set thumbnails on the owner's own channels. It does not read comments, subscribers, analytics or any other user's data.

How data is used, stored and shared

The OAuth sign-in token is stored only on the owner's own computer and is used only to upload the owner's videos. After each upload the app keeps a small record (video ID and link) on that computer. The app does not collect, sell, share or transfer any personal data or YouTube API data to anyone, does not use it for advertising, and does not place cookies or tracking on any device. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data and revoking access

Access can be revoked at any time on the Google security settings page: security.google.com/settings/security/permissions. When access is revoked, or on request, the stored token and upload records are deleted from the owner's computer within 7 days. The app does not store any YouTube API data for longer than it needs to complete an upload.

Contact

Questions about this policy can be raised at github.com/aqeelmumtaz-ai/apna-channels/issues.
